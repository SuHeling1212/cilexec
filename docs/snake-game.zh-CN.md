# 贪吃蛇游戏

`cilexec/snake/0.0.3` 是一个完全使用 FCL 编写的全屏终端游戏。它展示了 FCL
对象、持久化进程延续、结构化按键输入、定时等待、ANSI 绘制以及事务提交后的
`term.render` 画面通道。

从配置好的市场取得包数据库的精确 SHA-256，安装并导入：

```fcl
market.update()
market.install("<snake-package-sha256>")
import "<snake-package-sha256>" as "snake"
snake.play()
```

也可以通过 `package.run("<snake-package-sha256>")`直接启动这个应用包。

操作方式：

| 按键 | 操作 |
| --- | --- |
| 方向键或 `W/A/S/D` | 改变蛇的前进方向 |
| `P` | 暂停或继续 |
| `R` | 游戏结束后重新开始 |
| `Q` | 退出并返回最终分数 |

新游戏会按照当前终端尺寸创建棋盘，最大为40列、20行。调整终端尺寸会重新绘制
当前棋盘；如果窗口变得太小，游戏状态保持不变，并提示用户放大窗口。

棋盘采用环形空间，没有会致死的墙壁：蛇越过左边会从右边出现，越过右边会从
左边出现；越过上边会从下边出现，越过下边会从上边出现。蛇撞到自己的身体时
仍然会结束游戏。

每个完成的 FCL 执行切片都会先持久化 `SnakeGame` 对象，然后才发布画面。Runtime
或 Docker 崩溃可能丢失当前重绘和正在执行的移动，但恢复后会从最后一次提交的完整
游戏状态继续。ANSI 画面本身不会持久化，因为它可以从游戏状态重新生成。
