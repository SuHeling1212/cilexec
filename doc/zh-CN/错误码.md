# 错误码参考

## 返回值规范

所有返回 `String[]` 的函数遵循统一格式：
- 成功：`["SUCCESS", null]` 或 `["SUCCESS", data]`
- 失败：`["ERROR", "ERROR_CODE"]`

## 错误码详细说明

### 路径验证错误码

#### `PATH_TRAVERSAL_DETECTED`

**描述**：检测到路径遍历攻击，系统拒绝访问。

**原因**：
- 路径中包含 `..` 等目录遍历字符，试图访问虚拟文件系统（VFS）根目录之外的文件
- 规范化后的路径超出了 VFS 根目录范围
- 路径中包含 `~` 等特殊字符

**解决方案**：
1. 检查路径是否包含 `..`、`~` 等特殊字符
2. 确保路径在 VFS 根目录范围内
3. 使用相对路径时，确认基准路径正确
4. 避免使用用户输入直接构造文件路径

**示例**：
```
错误：/user/../../../etc/passwd
正确：/user/local/app/data.txt
```

#### `INVALID_PATH`

**描述**：路径格式无效或为空。

**原因**：
- 路径为空字符串或 null
- 路径格式不符合规范
- 路径包含非法字符（非字母、数字、下划线、连字符、点）

**解决方案**：
1. 确保路径不为空
2. 检查路径格式是否正确（应以 `/` 开头）
3. 确保路径组件只包含允许的字符：字母、数字、`_`、`-`、`.`

**示例**：
```
错误：user/data（缺少开头的 /）
错误：/user/data@file（包含非法字符 @）
正确：/user/local/app/data.txt
```

#### `INVALID_NAME`

**描述**：文件名或目录名无效。

**原因**：
- 名称为空或只包含空格
- 名称以 `.` 开头（隐藏文件）
- 名称包含非法字符（非字母、数字、下划线、连字符、点）
- 名称包含路径分隔符 `/` 或 `\`

**解决方案**：
1. 确保名称不为空
2. 名称不能以 `.` 开头
3. 名称只能包含字母、数字、`_`、`-`、`.`
4. 不要在名称中包含路径分隔符

**示例**：
```
错误：.hidden（以点开头）
错误：file@name（包含非法字符 @）
错误：dir/file（包含路径分隔符）
正确：data_file-2024.txt
```

#### `INVALID_SOURCE_PATH`

**描述**：源路径无效。

**原因**：
- 源路径为空或格式错误
- 源路径包含非法字符

**解决方案**：
1. 检查源路径格式
2. 确保源路径符合路径命名规范
3. 参考 `INVALID_PATH` 的解决方案

#### `INVALID_NEW_NAME`

**描述**：新名称无效。

**原因**：
- 新名称不符合命名规范
- 新名称包含非法字符
- 新名称以 `.` 开头

**解决方案**：
1. 参考 `INVALID_NAME` 的解决方案
2. 确保新名称符合命名规范
